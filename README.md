# STAYCLOSE New Corporate Site v4

## まず開くもの
- `index.html` : トップページ本体
- `design-reference/MASTER-approved-top.png` : 正式デザインマスター
- `CURSOR_PROMPT.md` : Cursorにそのまま貼るプロンプト
- `docs/HTML-CSS-STRUCTURE.md` : HTML/CSS構成案

## ローカル表示
Cursorのターミナルでこのフォルダを開き、以下を実行します。

```bash
python -m http.server 8080
```

ブラウザで `http://localhost:8080` を開きます。
